# AI Lab - Universiti Teknologi PETRONAS (UTP)

Welcome to the AI Lab repository! This repository contains all the lab assignments, projects, and resources for the Artificial Intelligence course at UTP. 

## 📚 Contents

*   **Lab Assignments:** Source code, scripts, and reports for our weekly AI lab sessions (e.g., Search Algorithms, BFS, DFS, A*).
*   **Projects:** Mini-projects exploring core AI concepts and problem-solving techniques.
*   **Resources:** Datasets, notes, and references used throughout the course.

## 🚀 Getting Started

To run the code in this repository locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/akriii/AI_Lab
   ```
2. Navigate into the directory:
   ```bash
   cd AI_Lab
   ```
3. Follow the specific instructions provided inside each individual lab folder.

## 🛠️ Technologies Used

*   Jupyter Notebook / Google Colab
*   Standard AI/ML Libraries (NumPy, Pandas, etc.)
